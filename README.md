# Logistics Pro - Full Stack Application

This is a PERN stack application for managing income and expenses, designed specifically for truckers and logistics professionals.

## Tech Stack
- **Frontend:** Next.js, Tailwind CSS, TypeScript
- **Backend:** Node.js, Express, Prisma ORM
- **Database:** PostgreSQL (Neon)
- **Deployment:** Vercel (Frontend), Render (Backend)

## Structure
- `/frontend`: Next.js application
- `/backend`: Node.js/Express API with Prisma

## Deployment
- The backend is deployed on **Render**.
- The frontend is deployed on **Vercel**.
- Database is hosted on **Neon**.
